# Как запустить ИИгру

Есть два способа сыграть без онлайн-трансляции — от самого простого к более полному. Что меняется для трансляции, описано [в примечании в конце](#примечание-онлайн-трансляция)¹.

| | Способ 1. Один экран | Способ 2. Зал с телефонами |
|---|---|---|
| Что нужно | Только браузер | Ноутбук ведущего + общий Wi-Fi |
| Как играют | Командами, ведущий сам начисляет очки | Каждый со своего телефона, очки и рейтинг считаются автоматически |
| Чат, голосование за плитку | Нет | Есть |
| Самостоятельные варианты с кодами призов | Нет | Есть |

---

## Вопросы: правка в Excel, без кода

Все вопросы лежат в двух таблицах:

| Файл | Что внутри | Где хранится |
|---|---|---|
| `questions.csv` | Обычные варианты 1, 2, 3 … и пасхальный `ML` | В репозитории (он публичный) |
| `live_questions.csv` | 25 вопросов трансляции | **Только у организатора.** В git не попадает, на сервер кладётся отдельно |

Столбцы (первая строка таблицы):

`Вариант` · `Тема` · `Очки` · `Вопрос` · `Правильный ответ` · `Неверный 1` · `Неверный 2` · `Неверный 3`

Правила:
- В каждом варианте 5 тем. В каждой теме ровно по одному вопросу на 100, 200, 300, 400 и 500 очков.
- Правильный ответ всегда пишите в свой столбец. На экране четыре варианта перемешиваются автоматически.
- Обычные варианты нумеруются подряд с 1. Можно добавить 12-й, 13-й и так далее — в игре они появятся сами.
- Ответы лучше делать короткими, в 1–3 слова. Следите, чтобы один вопрос варианта не подсказывал ответ на другой.
- Вопросы трансляции не должны повторять вопросы из `questions.csv`, иначе их можно заранее найти в публичном репозитории.

**Как редактировать.**
1. Откройте файл двойным щелчком в Excel. Таблицы сохранены в UTF-8 с разделителем «;», так что русский Excel открывает их без настроек.
2. Правьте.
3. Сохраните через «Файл → Сохранить как → CSV UTF-8». Подойдёт и обычный «CSV (разделители — запятые)»: программа понимает и «;», и «,», и кодировку Windows-1251.

**Проверка перед запуском:**

```bash
python3 tools/check_questions.py
```

Скрипт покажет ошибки с номерами строк — например, «в теме „Кино“ нет вопроса на 300» или «варианты ответа повторяются». Ещё он предупредит, если вопрос трансляции повторяет вопрос из обычных вариантов.

**Как применить изменения:**

| Где играете | Что сделать |
|---|---|
| Сервер на ноутбуке (способ 2) | Перезапустить сервер: Ctrl+C и снова команда запуска |
| Один экран (способ 1) | `python3 tools/build_offline.py` — перенесёт вопросы в `offline/index.html` |
| Сервер трансляции | См. [примечание](#примечание-онлайн-трансляция) ниже |

Если `live_questions.csv` с ошибкой, сервер всё равно запустится на обычном варианте. На пульте ведущего жёлтая полоса покажет, что не так с файлом.

## Способ 1. Один экран, без сервера

Подходит для игры в одной комнате: экран или проектор, ведущий кликает, команды отвечают вслух.

1. Скачайте файл [`offline/index.html`](offline/index.html). На GitHub это кнопка «Download raw file».
2. Откройте его двойным щелчком в любом браузере.
3. Добавьте или переименуйте команды в строке со счётом.
4. Выберите вариант вопросов в списке справа вверху. Их 11; пять быстрых нажатий на логотип открывают пасхальный ML-хардкор.
5. Кликните по цене вопроса, дайте командам ответить и нажмите «Показать ответ». Затем кнопкой с названием команды начислите очки или нажмите «Никто не ответил».

Счёт сохраняется в браузере, так что если случайно закрыть вкладку, игра продолжится с того же места. «Начать заново» обнуляет всё.

## Способ 2. Игра в зале: ноутбук ведущего и телефоны игроков

Ноутбук ведущего становится сервером. Игроки в той же Wi-Fi-сети сканируют QR-код и играют каждый со своего телефона: регистрация без личных данных, голосование за плитку, ответы на время, таблица лидеров, чат.

### Что нужно

- Ноутбук на macOS, Windows или Linux с Python 3.10 или новее.
  - Проверить: `python3 --version` (на Windows — `py --version`).
  - Скачать: [python.org/downloads](https://www.python.org/downloads/). На Windows при установке отметьте галочку «Add Python to PATH».
- Все игроки в **одной сети** с ноутбуком.
  - Гостевой Wi-Fi часто запрещает устройствам видеть друг друга. Если телефоны не открывают страницу, раздайте интернет с телефона ведущего и подключите к нему ноутбук и игроков. Для небольшой группы этого хватит.

### Первый запуск (один раз)

macOS / Linux, в Терминале:

```bash
git clone https://github.com/4god/iigra-online-quiz.git
cd iigra-online-quiz
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Windows, в PowerShell:

```powershell
git clone https://github.com/4god/iigra-online-quiz.git
cd iigra-online-quiz
py -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

Если `git` не установлен, на странице репозитория нажмите «Code → Download ZIP» и распакуйте архив.

### Запуск игры

macOS / Linux:

```bash
source .venv/bin/activate
HOST_KEY=мойключ LIVE_OPENS_AT=2000-01-01T00:00:00+03:00 LIVE_VARIANT=1 \
  python3 -m uvicorn server:app --host 0.0.0.0 --port 8000
```

Windows (PowerShell):

```powershell
.venv\Scripts\Activate.ps1
$env:HOST_KEY="мойключ"; $env:LIVE_OPENS_AT="2000-01-01T00:00:00+03:00"; $env:LIVE_VARIANT="1"
python -m uvicorn server:app --host 0.0.0.0 --port 8000
```

Что значат параметры:
- `HOST_KEY` — пароль ведущего, придумайте любой.
- `LIVE_OPENS_AT` в прошлом — игра доступна сразу. Без этого параметра игроки не смогут присоединиться до даты эфира.
- `LIVE_VARIANT` — какой из 11 вариантов играть (1–11).

При первом запуске Windows или macOS спросит, разрешить ли входящие подключения для Python. Нажмите «Разрешить», иначе телефоны не достучатся до ноутбука.

### Узнайте адрес ноутбука

- macOS: Системные настройки → Wi-Fi → Подробнее → IP-адрес. Или в Терминале: `ipconfig getifaddr en0`.
- Windows: `ipconfig` в PowerShell, строка «IPv4-адрес» у Wi-Fi-адаптера.

Пусть это `192.168.1.23`.

### Проведение

1. На ноутбуке откройте **`http://192.168.1.23:8000/host`** — именно по IP, а не `localhost`. QR-код на пульте показывает тот адрес, по которому открыт пульт.
2. Введите `HOST_KEY`. Выведите пульт на проектор.
3. Игроки сканируют QR с экрана (или вводят `http://192.168.1.23:8000`), придумывают логин и пароль, получают ID и нажимают «Присоединиться к трансляции».
4. Дальше всё как в эфире:
   - «Начать голосование» → «Завершить голосование» → клик по выигравшей плитке.
   - Игроки отвечают на телефонах, вы нажимаете «Показать ответ», таблица лидеров обновляется сразу.
5. После последнего вопроса у всех откроется итоговая таблица.
6. Чтобы после игры участники могли пройти остальные варианты и получить коды призов, включите в «Настройках» переключатель «Самостоятельные варианты». Коды проверяются на `http://192.168.1.23:8000/verify`.

Все данные (аккаунты, очки, коды) лежат в файле `data/iigra.db` рядом с программой. Удалите его, чтобы начать с нуля. Чтобы остановить сервер, нажмите в окне терминала Ctrl+C.

### Если что-то не так

| Проблема | Что сделать |
|---|---|
| Телефоны не открывают адрес | Проверьте, что ноутбук и телефоны в одной сети, Python разрешён в брандмауэре, а адрес набран с `:8000`. Попробуйте раздать сеть с телефона. |
| На пульте жёлтая полоса «трансляция откроется …» | Не задан `LIVE_OPENS_AT` в прошлом — перезапустите командой выше. |
| На пульте жёлтая полоса «вопросы трансляции не загружены» | Это нормально для игры в зале: играется вариант из `LIVE_VARIANT`. |
| Ноутбук уснул посреди игры | Отключите сон на время игры. После пробуждения телефоны переподключатся сами, очки сохранятся. |

## Примечание: онлайн-трансляция

¹ Для эфира на ~1000 человек используется тот же код, но с отличиями:

- **Публичный адрес с HTTPS**, а не ноутбук в локальной сети.
- **База переживает перезапуски.** Аккаунты регистрируют заранее, а коды призов проверяют ещё недели после эфира.
- **Вопросы трансляции — отдельный уникальный набор.** Его нет в репозитории: он лежит у организатора в `live_questions.csv`. На сервер его кладут файлом или переменной `LIVE_QUESTIONS`.
- **Время открытия.** Присоединиться к трансляции нельзя до `LIVE_OPENS_AT`. По умолчанию это 12 ноября 2026, 00:00 МСК. Регистрироваться можно заранее: до этого момента сервер сам отклоняет голоса, ответы и сообщения в чат.

Ниже весь путь по шагам: сервер в Yandex Cloud → проверка → предрегистрация → день эфира → после эфира.

### Шаг 1. Аккаунт в Yandex Cloud

1. Зарегистрируйтесь в [Yandex Cloud](https://yandex.cloud) и войдите в [консоль](https://console.yandex.cloud).
2. Billing → «Создать аккаунт» → физлицо, привяжите банковскую карту.
   - Стартового гранта для новых клиентов в 2026 году [нет](https://yandex.cloud/ru/docs/getting-started/usage-grant).
   - Оплата постфактум: за месяц спишут с карты [в начале следующего месяца](https://yandex.cloud/ru/docs/billing/payment/payment-methods-individual).
3. На странице платёжного аккаунта: «Привязанные облака» → «Привязать» → ваше облако. Без этого консоль не даст создать машину и будет показывать «Permission denied».

### Шаг 2. Виртуальная машина

Compute Cloud → «Создать виртуальную машину»:

- **Образ:** Ubuntu 24.04.
- **Диск:** HDD 20 ГБ. SSD не нужен.
- **Вычислительные ресурсы:** Standard → Intel 2 vCPU, 4 ГиБ RAM (доля vCPU 100%).
- **Публичный IP:** «Автоматически».
- **Доступ:** «SSH-ключ», придумайте логин, например `deploy`, и добавьте свой открытый SSH-ключ.
  - Создать ключ: `ssh-keygen -t ed25519 -f ~/.ssh/iigra_yc`. В форму вставляется содержимое файла `~/.ssh/iigra_yc.pub`.
- **Резервное копирование: выключите.** Оно включено по умолчанию и стоит около 280 ₽/мес.

После создания сделайте IP постоянным, чтобы ссылка и QR не менялись после остановки машины: Virtual Private Cloud → «Публичные IP-адреса» → «⋯» у адреса машины → «Сделать статическим».

Группа безопасности по умолчанию пропускает весь трафик. Ограничивать её не нужно: скрипт установки сам включит на машине фаервол и оставит открытыми только порты 22, 80 и 443.

### Шаг 3. Установка игры

В командах ниже `ЛОГИН` — логин из формы, `IP` — адрес машины.

1. Скопируйте вопросы трансляции на машину:
   ```bash
   scp -i ~/.ssh/iigra_yc live_questions.csv ЛОГИН@IP:/tmp/
   ```
2. Запустите установку:
   ```bash
   ssh -i ~/.ssh/iigra_yc ЛОГИН@IP
   curl -fsSLO https://raw.githubusercontent.com/4god/iigra-online-quiz/main/deploy/setup_vm.sh
   sudo bash setup_vm.sh --host-key МОЙКЛЮЧ --ip IP --live-questions /tmp/live_questions.csv \
        --opens-at 2026-11-12T00:00:00+03:00
   ```
   - Скрипт ставит Python, Caddy и фаервол, настраивает автозапуск и HTTPS.
   - В конце он печатает адрес вида `https://1-2-3-4.sslip.io`. Это бесплатный домен, который указывает на IP машины.
   - Свой домен можно передать параметром `--domain`.
3. Запишите ключ ведущего и адрес в надёжное место. В репозиторий их не кладите: он публичный.

### Шаг 4. Проверка

1. **Полный сценарий.** На время проверки откройте трансляцию: повторите команду установки с `--opens-at 2000-01-01T00:00:00+03:00`. Затем на своём компьютере, в папке репозитория:
   ```bash
   python3 tools/e2e_test.py https://АДРЕС МОЙКЛЮЧ
   ```
   В конце должно быть `ALL OK`.
2. **Нагрузка, при желании.** Тест на 1000 игроков запускайте **с самой машины**: из дома роутер обычно не даёт открыть больше ~1000 соединений, и результат будет хуже реального.
   - Временно добавьте `REGISTER_LIMIT=100000` в `/etc/iigra.env` и выполните `sudo systemctl restart iigra`.
   - На машине: `echo "127.0.0.1 АДРЕС-БЕЗ-https" | sudo tee -a /etc/hosts`, затем запуск `tools/load_test.py` (нужен `pip install aiohttp`).
   - После теста удалите эту строку из `/etc/hosts`.
3. **Корпоративная сеть.** Если зрители будут смотреть с рабочих компьютеров, откройте адрес из рабочей сети. Некоторые корпоративные фильтры блокируют бесплатные домены вроде `sslip.io`; тогда нужен свой домен (`--domain`).
4. **Очистка после тестов.** Удалите тестовые аккаунты и верните дату открытия:
   ```bash
   sudo systemctl stop iigra
   sudo rm -f /var/lib/iigra/iigra.db*
   sudo bash setup_vm.sh --host-key МОЙКЛЮЧ --ip IP --opens-at 2026-11-12T00:00:00+03:00
   ```
   Повторный запуск скрипта перезаписывает `/etc/iigra.env`, поэтому `REGISTER_LIMIT` пропадёт сам.

### Шаг 5. Предрегистрация

Чтобы к эфиру все были готовы, раздайте ссылку заранее: люди регистрируются, а в день эфира просто входят.

1. **Переведите машину в экономный режим.** Для регистраций полной мощности не нужно: 500 регистраций подряд проходят за 3 секунды.
   - Консоль → `iigra` → «⋯» → «Остановить».
   - «Редактировать» → вкладка **Shared-core** → доля **20%** → **2 vCPU, 2 ГиБ RAM** → «Сохранить изменения».
   - «Запустить». Игра поднимется сама через минуту.
2. **Раздайте ссылку и QR-код** (`https://АДРЕС/qr`). Шаблон анонса:

   > **ИИгра: «Своя игра» про искусственный интеллект 🤖**
   >
   > 12 ноября в [время] проведём онлайн-викторину про ИИ. Каждый играет сам за себя, вопросы выбираем голосованием, результаты сразу попадают в таблицу лидеров.
   >
   > **Зарегистрируйтесь заранее, это займёт минуту:** [ссылка]
   >
   > 1. Придумайте логин и пароль. Имя, почта и телефон не нужны.
   > 2. Сделайте скриншот экрана с вашим ID: по нему выдаются призы.
   > 3. Запомните логин и пароль. Восстановить пароль нельзя.
   >
   > **12 ноября** откройте ту же ссылку, войдите под своим логином и паролем и нажмите «Присоединиться к трансляции».

### Шаг 6. День эфира

1. **Утром верните полную мощность. Это обязательно**: экономного режима на 1000 игроков не хватит.
   - «Остановить» → «Редактировать» → вкладка **Standard** → **Intel 2 vCPU, 4 ГиБ RAM** → «Сохранить» → «Запустить».
   - Сайт будет недоступен около 3 минут, аккаунты сохранятся.
   - На странице машины должно быть «Гарантированная доля vCPU: 100%».
2. **За 15–30 минут до эфира:**
   - Откройте `/host` и введите ключ. На пульте не должно быть жёлтой полосы про вопросы.
   - Прогоните один вопрос с коллегами, затем «Настройки → Сбросить игру» (подтверждение словом «СБРОС»). Сброс обнуляет очки и плитки, но не удаляет аккаунты.
   - «Самостоятельные варианты» должны быть выключены.
3. **В 00:00 даты открытия** кнопка «Присоединиться к трансляции» у игроков станет активной сама.
4. **Во время эфира ничего не обновляйте и не перезапускайте.** Рестарт не теряет аккаунты и очки, но открытый в этот момент вопрос пропадёт.

### Шаг 7. После эфира

1. На пульте → «Настройки» скачайте CSV с итоговым рейтингом.
2. Включите «Самостоятельные варианты», если нужны призы за них. Коды проверяются на `/verify`, их список — тоже в CSV.
3. Сохраните копию базы. Это все аккаунты, очки и коды:
   ```bash
   ssh -i ~/.ssh/iigra_yc ЛОГИН@IP 'sudo sqlite3 /var/lib/iigra/iigra.db ".backup /tmp/iigra-backup.db" && sudo chmod 644 /tmp/iigra-backup.db'
   scp -i ~/.ssh/iigra_yc ЛОГИН@IP:/tmp/iigra-backup.db .
   ```
4. **Пока нужны самостоятельные варианты,** держите машину в экономном режиме, как в шаге 5.
5. **Когда сервер больше не нужен,** удалите ресурсы, иначе за них продолжат начислять деньги:
   - Compute Cloud → `iigra` → «⋯» → «Удалить». Диск удалится вместе с машиной.
   - Virtual Private Cloud → «Публичные IP-адреса» → «⋯» → «Удалить».
   - Проверьте в Billing → «Детализация», что начисления прекратились.
   - Последнее списание придёт в начале следующего месяца. После него карту можно отвязать.

### Сколько стоит

Цены Yandex Cloud на ноябрь 2026, с НДС:

| Состояние | ₽ в сутки |
|---|---|
| Полная мощность (2 vCPU 100%, 4 ГБ) | ≈ 100 |
| Экономный режим (2 vCPU 20%, 2 ГБ) | ≈ 49 |
| Машина остановлена (диск и постоянный IP) | ≈ 17 |
| Трафик | 0, первые 100 ГБ в месяц бесплатны |

Консоль показывает цену за месяц непрерывной работы: ≈ 3000 ₽ для полной мощности.

### Обслуживание

```bash
ssh -i ~/.ssh/iigra_yc ЛОГИН@IP
sudo journalctl -u iigra -n 50 --no-pager     # логи игры
sudo journalctl -u caddy -n 50 --no-pager     # логи HTTPS
sudo systemctl restart iigra                   # перезапуск (аккаунты и очки сохраняются)
```

- **Обновить код:** снова запустите `setup_vm.sh` с теми же параметрами. Он подтянет новую версию с GitHub и перезапустит сервис, база не трогается. Сам скрипт лежит на машине в `/opt/iigra/deploy/setup_vm.sh`.
- **Настройки** лежат в `/etc/iigra.env`, база — в `/var/lib/iigra/iigra.db`.
- **Заменить вопросы трансляции:**
  ```bash
  scp -i ~/.ssh/iigra_yc live_questions.csv ЛОГИН@IP:/tmp/
  ssh -i ~/.ssh/iigra_yc ЛОГИН@IP 'sudo cp /tmp/live_questions.csv /opt/iigra/ && sudo systemctl restart iigra'
  ```
- **Обычные варианты** меняются через `questions.csv` в репозитории и повторный запуск `setup_vm.sh`.

### Если что-то не так

| Проблема | Что сделать |
|---|---|
| Сайт не открывается | В консоли проверьте, что машина в статусе Running. Если она работает — `sudo systemctl status iigra caddy` и логи выше. |
| Сайт не открывается из офиса, а с телефона по мобильной сети открывается | Корпоративный фильтр блокирует `sslip.io`. Нужен свой домен: A-запись на IP машины, затем `setup_vm.sh … --domain game.example.ru`. |
| В консоли «Permission denied» | К облаку не привязан платёжный аккаунт (шаг 1). |
| Жёлтая полоса «вопросы трансляции не загружены» | Нет или испорчен `/opt/iigra/live_questions.csv`. Текст ошибки — на полосе. Проверка: `python3 tools/check_questions.py`. |
| Игрок забыл пароль | Восстановить нельзя. Пусть зарегистрируется заново с другим логином. |

**Почему не Render:** на бесплатном тарифе сервис засыпает через 15 минут без трафика, при каждом засыпании и перезапуске стирает базу и даёт 0,1 CPU. Если всё же нужен Render, берите платный Starter или Standard с persistent disk для `DATA_DIR`.
