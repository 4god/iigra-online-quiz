# Как запустить ИИгру

Есть два способа сыграть без онлайн-трансляции — от самого простого к более полному. Что меняется для трансляции, описано [в примечании в конце](#примечание-онлайн-трансляция)¹.

| | Способ 1. Один экран | Способ 2. Зал с телефонами |
|---|---|---|
| Что нужно | Только браузер | Ноутбук ведущего + общий Wi-Fi |
| Как играют | Командами, ведущий сам начисляет очки | Каждый со своего телефона, очки и рейтинг считаются автоматически |
| Чат, голосование за плитку | Нет | Есть |
| Самостоятельные варианты с кодами призов | Нет | Есть |

---

## Способ 1. Один экран, без сервера

Подходит для игры в одной комнате: экран или проектор, ведущий кликает, команды отвечают вслух.

1. Скачайте файл [`offline/index.html`](offline/index.html). На GitHub это кнопка «Download raw file».
2. Откройте его двойным щелчком в любом браузере.
3. Добавьте или переименуйте команды в строке со счётом.
4. Выберите вариант вопросов в списке справа вверху. Их 11; пять быстрых нажатий на логотип открывают пасхальный ML-хардкор.
5. Кликните по цене вопроса, дайте командам ответить и нажмите «Показать ответ». Затем кнопкой с названием команды начислите очки или нажмите «Никто не ответил».

Счёт сохраняется в браузере, так что если случайно закрыть вкладку, игра продолжится с того же места. «Начать заново» обнуляет всё.

## Способ 2. Игра в зале: ноутбук ведущего и телефоны игроков

Ноутбук ведущего становится сервером. Игроки в той же Wi-Fi-сети сканируют QR-код и играют каждый со своего телефона: регистрация без личных данных, голосование за плитку, ответы на время, таблица лидеров, чат.

### Что нужно

- Ноутбук на macOS, Windows или Linux с Python 3.10 или новее.
  - Проверить: `python3 --version` (на Windows — `py --version`).
  - Скачать: [python.org/downloads](https://www.python.org/downloads/). На Windows при установке отметьте галочку «Add Python to PATH».
- Все игроки в **одной сети** с ноутбуком.
  - Гостевой Wi-Fi часто запрещает устройствам видеть друг друга. Если телефоны не открывают страницу, раздайте интернет с телефона ведущего и подключите к нему ноутбук и игроков. Для небольшой группы этого хватит.

### Первый запуск (один раз)

macOS / Linux, в Терминале:

```bash
git clone https://github.com/4god/iigra-online-quiz.git
cd iigra-online-quiz
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Windows, в PowerShell:

```powershell
git clone https://github.com/4god/iigra-online-quiz.git
cd iigra-online-quiz
py -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

Если `git` не установлен, на странице репозитория нажмите «Code → Download ZIP» и распакуйте архив.

### Запуск игры

macOS / Linux:

```bash
source .venv/bin/activate
HOST_KEY=мойключ LIVE_OPENS_AT=2000-01-01T00:00:00+03:00 LIVE_VARIANT=1 \
  python3 -m uvicorn server:app --host 0.0.0.0 --port 8000
```

Windows (PowerShell):

```powershell
.venv\Scripts\Activate.ps1
$env:HOST_KEY="мойключ"; $env:LIVE_OPENS_AT="2000-01-01T00:00:00+03:00"; $env:LIVE_VARIANT="1"
python -m uvicorn server:app --host 0.0.0.0 --port 8000
```

Что значат параметры:
- `HOST_KEY` — пароль ведущего, придумайте любой.
- `LIVE_OPENS_AT` в прошлом — игра доступна сразу. Без этого параметра игроки не смогут присоединиться до даты эфира.
- `LIVE_VARIANT` — какой из 11 вариантов играть (1–11).

При первом запуске Windows или macOS спросит, разрешить ли входящие подключения для Python. Нажмите «Разрешить», иначе телефоны не достучатся до ноутбука.

### Узнайте адрес ноутбука

- macOS: Системные настройки → Wi-Fi → Подробнее → IP-адрес. Или в Терминале: `ipconfig getifaddr en0`.
- Windows: `ipconfig` в PowerShell, строка «IPv4-адрес» у Wi-Fi-адаптера.

Пусть это `192.168.1.23`.

### Проведение

1. На ноутбуке откройте **`http://192.168.1.23:8000/host`** — именно по IP, а не `localhost`. QR-код на пульте показывает тот адрес, по которому открыт пульт.
2. Введите `HOST_KEY`. Выведите пульт на проектор.
3. Игроки сканируют QR с экрана (или вводят `http://192.168.1.23:8000`), придумывают пароль, получают ID и нажимают «Присоединиться к трансляции».
4. Дальше всё как в эфире:
   - «Начать голосование» → «Завершить голосование» → клик по выигравшей плитке.
   - Игроки отвечают на телефонах, вы нажимаете «Показать ответ», таблица лидеров обновляется сразу.
5. После последнего вопроса у всех откроется итоговая таблица.
6. Чтобы после игры участники могли пройти остальные варианты и получить коды призов, включите в «Настройках» переключатель «Самостоятельные варианты». Коды проверяются на `http://192.168.1.23:8000/verify`.

Все данные (аккаунты, очки, коды) лежат в файле `data/iigra.db` рядом с программой. Удалите его, чтобы начать с нуля. Чтобы остановить сервер, нажмите в окне терминала Ctrl+C.

### Если что-то не так

| Проблема | Что сделать |
|---|---|
| Телефоны не открывают адрес | Проверьте, что ноутбук и телефоны в одной сети, Python разрешён в брандмауэре, а адрес набран с `:8000`. Попробуйте раздать сеть с телефона. |
| На пульте жёлтая полоса «трансляция откроется …» | Не задан `LIVE_OPENS_AT` в прошлом — перезапустите командой выше. |
| На пульте жёлтая полоса «вопросы трансляции не загружены» | Это нормально для игры в зале: играется вариант из `LIVE_VARIANT`. |
| Ноутбук уснул посреди игры | Отключите сон на время игры. После пробуждения телефоны переподключатся сами, очки сохранятся. |

## Примечание: онлайн-трансляция

¹ Для эфира на ~1000 человек используется тот же код, но с отличиями:

- **Публичный адрес с HTTPS**, а не ноутбук в локальной сети.
- **База должна переживать перезапуски.** Коды призов проверяют ещё недели после эфира.
- **Вопросы трансляции — отдельный уникальный набор.** Его нет в репозитории: он лежит в `live_questions.json` у организатора (и в Excel-файле с ответами). На сервер его кладут файлом или переменной `LIVE_QUESTIONS`.
- **Время открытия.** Присоединиться к трансляции нельзя до `LIVE_OPENS_AT`; по умолчанию это 12 ноября 2026, 00:00 МСК. Регистрироваться можно заранее. Сервер до этого момента сам отклоняет голоса, ответы и сообщения в чат.

### Где разместить: Yandex Cloud на стартовом гранте

Render на бесплатном тарифе не подходит:
- сервис засыпает через 15 минут без трафика;
- при каждом засыпании и перезапуске стирает базу, то есть аккаунты и коды призов;
- даёт 0,1 CPU.

Новым пользователям Yandex Cloud даёт [стартовый грант 4 000 ₽ на 60 дней](https://yandex.cloud/ru/docs/getting-started/usage-grant). После его окончания деньги [не списываются автоматически](https://yandex.cloud/ru/docs/free-trial/concepts/trial-ending): нужно самому перейти на платную версию. Грант покрывает и день эфира, и несколько недель самостоятельных вариантов.

1. **Регистрация.** Зарегистрируйтесь в [Yandex Cloud](https://yandex.cloud) как физлицо и привяжите карту **при создании** платёжного аккаунта, иначе грант не начислится.
2. **Виртуальная машина.** Compute Cloud → Создать ВМ:
   - образ **Ubuntu 24.04**;
   - **2 vCPU, гарантированная доля 100%, 4 ГБ RAM**, диск 20 ГБ;
   - публичный IP — автоматически;
   - добавьте свой SSH-ключ.
   - День работы такой машины стоит порядка 100 ₽ из гранта.
3. **Порты.** Если у сети есть группа безопасности, откройте входящие порты 22, 80 и 443.
4. **Вопросы трансляции.** Скопируйте их на машину:
   ```bash
   scp live_questions.json ubuntu@IP:/tmp/
   ```
5. **Установка.** Зайдите на машину и запустите скрипт:
   ```bash
   ssh ubuntu@IP
   curl -fsSLO https://raw.githubusercontent.com/4god/iigra-online-quiz/main/deploy/setup_vm.sh
   sudo bash setup_vm.sh --host-key МОЙКЛЮЧ --live-questions /tmp/live_questions.json \
        --opens-at 2026-11-12T00:00:00+03:00
   ```
   Скрипт ставит Python и Caddy, настраивает автозапуск и HTTPS и печатает адрес вида `https://1-2-3-4.sslip.io`. Это бесплатный домен, который указывает на IP машины. Свой домен можно передать параметром `--domain`.
6. **Репетиция.** Временно поставьте `--opens-at` в прошлое и повторите команду. Прогоните игру с коллегами, на пульте нажмите «Настройки → Сбросить игру». Затем верните `--opens-at` на дату эфира.
7. **После эфира** уменьшите машину до 2 vCPU с долей 20% и 2 ГБ RAM, чтобы грант дольше покрывал самостоятельные варианты. Регулярно копируйте `/var/lib/iigra/iigra.db` — это вся база игроков и кодов.

Обновить код на машине — тот же запуск `setup_vm.sh`: он подтянет новую версию и перезапустит сервис, база не трогается. **Во время эфира ничего не обновляйте.**

### Чек-лист в день эфира

- За 15 минут откройте `/host`. На пульте не должно быть жёлтой полосы про вопросы.
- В 00:00 указанной даты кнопка «Присоединиться к трансляции» у игроков станет активной сама.
- «Самостоятельные варианты» держите выключенными до конца эфира.
- Запасной вариант — Render на платном тарифе Starter или Standard с persistent disk. Подробности в [README](README.md).
